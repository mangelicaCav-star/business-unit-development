# Roles and Responsibilities

| Function | Historical responsibility |
|---|---|
| Operational Management | Unit initiative, oversight, escalation and selected decisions |
| Unit administrator | Operating model, costing, setup, requisitions, supplier and customer follow-up, logistics and financial review |
| Sales | Customer quotes and commercial negotiations |
| Purchasing | Supplier POs, corrections and import documentation with broker |
| Warehouse | Receipts and ERP registration |
| Invoicing | Deliveries, invoices and closing fully invoiced ERP projects |
| Finance | Financial controls and correction coordination |
| Customs broker | Customs clearance expertise and execution |
| Engineering | Independent engineering work; not administrator's direct reports |

Coordination and verification do not imply transaction ownership or approval authority.
