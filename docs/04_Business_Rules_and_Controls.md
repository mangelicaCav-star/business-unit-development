# Business Rules and Controls

| ID | Historical rule |
|---|---|
| BR-01 | Determine buying, selling and invoicing entity and physical route before costing. |
| BR-02 | Review import/NOM requirements with customs resources. |
| BR-03 | Preliminary costing before customer PO; official budget only after customer PO. |
| BR-04 | Include procurement, logistics, modeled import and delivery costs, FX and applicable VAT. Internal import allowances are not statutory customs duties. |
| BR-05 | Typical 30% **markup on cost**, not 30% margin on sales; adjustments depended on project. |
| BR-06 | Sales issues quotes; Sales and management handle later discounts. |
| BR-07 | Purchasing issues supplier POs after documented project requisition. |
| BR-08 | Customer scope changes require revised customer PO and preserved/versioned budget. |
| BR-09 | Additional purchasing uses a new supplier PO linked to same project. |
| BR-10 | Warehouse records receipts; invoice only delivered quantities. |
| BR-11 | Invoicing closes projects after full invoicing; cost reconciliation follows. |
| BR-12 | Administrator requests cost corrections from originating departments, without editing accounting. |
| BR-13 | Unresolved discrepancies retain ERP amounts with monthly report annotation. |
| BR-14 | Obtain written supplier dates; escalate material delays. |
| BR-15 | Extra expedited freight requires supplier funding or customer approval. |
| BR-16 | Initial brand inventory investments required management authorization. |

**Fictional arithmetic:** cost 1,000 × 1.30 = selling price 1,300; margin on sales = 300/1,300 = 23.08%.
