# Data Model and Governance

Historical ERP project IDs linked customer orders, requisitions, supplier purchases, costs and invoicing. US invoices could require separate confirmation. Supporting evidence was organized in shared project folders.

## Proposed entities (not implemented)
Project, CustomerPO, BudgetVersion, SupplierPO, Receipt, Delivery, Invoice and CostEntry.

## Proposed controls
Version preservation, legal-entity checks, currency checks, receipt-versus-delivery checks and documented cost discrepancy ownership. These are future enhancements, not historical claims.
